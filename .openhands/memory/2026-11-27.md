## Native memory (Rust)
- `internal.rs analyze_with_writer`: `drop(relocation)` right after Pass A; `drop(xrefs)` after the
  signature pass; `signatures.remove(address)` in the write loop so the map shrinks as rows go out.
  (`names.remove` was already incremental.)
- `xref.rs`: `XrefTable` is now flat arenas (`Vec<FunctionXrefs>` with `EdgeSpan` into `calls` /
  `data_refs`) plus `try_reserve` → `CoreError::OutOfMemory`, instead of `Vec<u64>` per function and
  two global `BTreeMap`s.
- `elf.rs`: `MappedLibrary::clear_shared_cache()` exposed as `clearMappedCacheNative` in
  `jni_bridge.rs` / `NativeLib.kt`; `MainViewModel.releaseLibrary()` and `clearCache()` call it
  before deleting files so a live mmap can never SIGBUS.
- ADRP/ADD decode: `rd != rn` accepted, `page[rd]` clobbered on writes, `ADR` and LDR
  32/64/byte/half forms decoded. `find_string_xrefs` pairs within 64 bytes.
- `collect_functions`: `fill_function_gaps` + BL/B targets run even when `.eh_frame` parsed;
  `is_probable_prologue` covers callee-saved STP and leaf entries.
- `jninatives.rs` `CLASS_SEARCH_WINDOW_BYTES = 16_384`.
