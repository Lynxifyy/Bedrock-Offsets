# 2026-11-28

## 3 GB scan peak follow-up

- `Signature` now stores `masks: Option<Box<[u32]>>`. Generated signatures leave it `None` and
  derive `keep_mask(word)` on demand; only signatures read back from an export carry explicit
  masks. `storage_bytes` counts the words plus any custom mask, not two arrays per signature.
- `internal::analyze_with_writer` uses the planner's address-sorted `Vec<(u64, Signature)>` in
  place. Vtable-slot lookup is a binary search; the function loop consumes entries with a cursor
  and replaces each drained `Signature` with `Signature::from_words(&[])` to free its words.
- Slot metadata and `SignatureExtras` are attached one drained class at a time, after
  `writer.meta`. `slots_with_size_zero` and `vtable_slots` are counted in a lightweight prepass
  before the header so no per-slot string map exists while every class is resident.
- `resolveVtablesToFileNative` lets the engine serialize the vtable JSON directly to a temp file;
  Kotlin parses it through a Gson `Reader` and deletes the temp file. `ScanCache.writeDocument`
  has an atomic `(Writer) -> Unit` overload, and `ResultCache` streams both store and load
  instead of building 30-100 MB strings.
- A JDK **is** present at `/workspace/tools/jdk-21.0.13+9`; export `JAVA_HOME` and add its bin to
  `PATH` before Gradle. `./gradlew test` passes 374 tests (debug and release), and
  `ktlintCheck`, `lintDebug`, `assembleRelease`, and `scripts/verify_release.py` also pass.
