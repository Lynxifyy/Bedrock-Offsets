
## Bedrock-Offsets (Lynxifyy/Bedrock-Offsets) — Android + Rust offset extractor

Feature branch `feat/offset-extractor-engine`. 30-phase plan, one commit per phase.

### Environment / build
- Env script: `source /workspace/tools/env.sh` (JDK 21, Android SDK 34/35, NDK
  27.3.13750724, Rust 1.99.1 + cargo-ndk, Gradle 8.13).
- Kotlin gate: `./gradlew test lintDebug assembleDebug --no-daemon` (~30-45s warm).
  Tests run in BOTH debug and release variants.
- Rust: `cd app/src/main/rust/offset_core && cargo test --offline`, `cargo fmt`,
  `cargo clippy --offline --all-targets -- -D warnings`.
- Stage the `.so` for the APK: `python3 scripts/build_rust.py --offline`.

### Gotchas learned (expensive)
- **`createComposeRule()` tests must live in `app/src/testDebug/`**, not
  `app/src/test/`: the release unit-test variant has no Compose test manifest
  activity, so all three tests fail there with "component is not displayed".
  `createAndroidComposeRule<MainActivity>()` works in `src/test` because the
  activity itself is the host.
- **Assert `assertExists()` rather than `assertIsDisplayed()`** for tall panels in
  a compose test: the default viewport is small, so lower fields exist in the tree
  but are off screen.
- **goblin `Elf::lazy_parse` leaves `section_headers` EMPTY.** Call
  `Elf::parse_header` then `SectionHeader::parse(image, e_shoff, e_shnum, ctx)`
  (ctx from `goblin::container::{Ctx, Container, Endian}`; `Endian` is re-exported
  from `goblin::container`, NOT `scroll`). `sections.rs::parse_section_headers`.
- JNI symbol naming must match the Kotlin external's **package + class + method**:
  `Java_com_chimerateam_offsetextractor_data_native_NativeLib_<method>`.
- ViewModel factory: use `viewModelFactory { initializer { ... } }`, not
  `viewModels { MainViewModel.create(...) }`.
- Log buffer lives in the composable (capped 500) collecting `viewModel.logs`.
