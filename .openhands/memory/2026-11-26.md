### The gates that actually bite (all run locally before pushing now)
Run the whole CI set, not just `testDebugUnitTest`:
```
./gradlew :app:testDebugUnitTest :app:testReleaseUnitTest   # 309 / 260
./gradlew ktlintCheck lintDebug
cargo fmt --all --check && cargo clippy --all-targets -- -D warnings
cargo test --all-targets && RUSTDOCFLAGS="-D warnings" cargo doc --no-deps
python3 -m unittest discover -s scripts/tests -t .
python3 scripts/generate_patterns.py patterns.txt && git diff --exit-code app/src/main/assets/patterns.json
```
- **`testReleaseUnitTest` runs too** and any Compose test (`createComposeRule`)
  placed in `src/test` fails there: the `ComponentActivity` host only exists in
  the **debug** manifest. Compose tests belong in `src/testDebug`.
- **ktlint**: `const val` must be SCREAMING_SNAKE_CASE (`MotionDuration.SHORT`,
  not `.Short`); a private flow named `_scanId` without an exposed `scanId`
  trips `property-naming`; imports are lexicographic with no blank lines
  (`java.*` sorts after `com.*`). `./gradlew ktlintFormat` fixes most.
- **rustdoc** treats `[id]`, `[writer]`, `[out]` in doc comments as intra-doc
  links; write them as code spans.
- **Android lint** `UsableSpace` fires on `File.usableSpace` in the preflight.
  Kept deliberately (getAllocatableBytes counts clearable caches, including the
  cached ZIP that Retry resumes from) with `@Suppress("UsableSpace")` + reason.
- **`verify_release.py` demands the classes in `GSON_MODEL_CLASSES` exist in the
  dex.** Deleting a model class (the JNI document is `JsonWriter`-streamed now,
  so `OffsetDocument`/`SourceInfo`/`VTableEntry`/`Stats` are gone) fails the
  release build with "shrunk away". Keep that tuple in step with the source.
- `Compose` `AnimatedVisibility` must be called by FQN inside a `Box` scope, or
  overload resolution picks the `RowScope` extension and fails to compile.

### Moving a release tag
`gh release create` runs on tag push and fails if the release exists, and
`PATCH /releases/tags/{tag}` is a 404 — PATCH needs the numeric release **id**.
To re-cut a release from a fixed commit: `DELETE /releases/{id}`, delete the tag
locally and remotely, re-create it on the new commit, push the tag, then PATCH
the body by id once the workflow finishes.
