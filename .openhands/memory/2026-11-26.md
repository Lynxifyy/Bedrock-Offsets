## Design decisions this session
- Palette is graphite (`Graphite950..100`, `Accent*`, `Secondary*`, semantic `Success/Warning/Error/Info`)
  with `LocalSemanticColors`; the blue/pink gradient app bar is gone and screens hold no literal colours.
- Navigation: bottom bar below 840 dp, `NavigationRail` at/above it; icons live on `AppTab`.
- Live log: "following" means the *last* item is visible (`visibleItemsInfo.last().index`), not
  `firstVisibleItemIndex >= last` (that is never true in a long list, so the pane never followed).
- A scan has an id: `beginScan()` stamps entries, empties the pane, deletes `cacheDir/logs/live.log`.
